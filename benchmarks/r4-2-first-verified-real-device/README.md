# R4.2 first verified real device benchmark

This benchmark records a deliberate partial result. KTP700 identity and
official physical dimensions are verified, but the supplied DXF crop fails the
source-to-physical aspect-ratio gate. The candidate is therefore not included
in `verified-device-set.json` as placement-capable.

The source PDF is cached under `catalog/r4_2/source-artifacts/`; no original
catalog DXF is copied or changed.
