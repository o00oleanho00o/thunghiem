Không phải AutoCAD clone

03 · USE CASES

Từ candidate tới component thật

01

AI bóc BOQ

Nhận diện panel, thiết bị trong/ngoài panel, quantity, manufacturer/model nếu có và technical properties. Output là candidate extraction, không phải engineering approval.

Raw project → Panel MDB-2B → candidate MCCB / MCB / SPD / Meter / CT
02

BOM intelligence

Normalize description, map manufacturer/type/order code, tìm duplicate và missing data, rồi nối vào catalog có trạng thái verified / unknown / needs-review.

Raw BOM → normalized BOM → catalog references
03

Real component library

Product identity + footprint + DXF/vector + provenance + mounting metadata + rules. Rectangle chỉ là solver envelope; UI có thể render geometry thật.

ABB S201U-C16 · type ≠ order code · bounds có provenance
04

Cabinet fit & selection

Thử nhiều enclosure, tính rail/duct/clearance/reserve, báo fit hoặc not fit. AI đề xuất; solver xác nhận.

600×800 · 800×1000 · 800×1200 · 1000×1400
