# R3.1b verified mini-catalog

This catalog is deliberately small and traceable. The eight ABB S201U-C type designations are reviewed extractions from one locally cached official ABB datasheet. Each type designation has a distinct manufacturer order code and a page/table locator. Fields not supported by the source are `unknown` and remain outside the authoritative geometry envelope.

The R3.1b benchmark uses only the eight ABB records in `products.json`. Exact-product CAD representations are unavailable, so the benchmark renders engineering envelopes as rectangles. The 0-degree orientation and 5 mm clearance are explicit CNB engineering policies, not ABB requirements.
