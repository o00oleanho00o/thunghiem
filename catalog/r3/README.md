# R3 verified mini-catalog

This catalog is deliberately small and traceable. Records are `review_verified`, not a claim that a live manufacturer endpoint was successfully crawled. The source URL is retained for procurement review; fields not supported by the source are listed in `known_unknowns` and remain outside the authoritative geometry envelope.

The R3 benchmark uses only the eight records in `products.json`. CAD representations are unavailable for these exact products, so the benchmark renders engineering footprints as rectangles and does not pretend that a supplied Siemens DXF belongs to a Phoenix Contact product.
