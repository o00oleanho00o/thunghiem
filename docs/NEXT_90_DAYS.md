# Next 90 Days

## Days 0-30: harden the engineering core

1. Generate browser types from the checked-in EIR JSON Schema and remove transitional hand-written field mappings.
2. Add a FastAPI revision API with optimistic concurrency, catalog snapshots, and a browser edit-to-EIR command path.
3. Expand validation to clearance classes, rail compatibility, terminal accessibility, reserve area, duplicate nets, and explicit capacity failures.
4. Add property-based and golden-file tests for 10/30/100-part panels, units, rotations, imports and deterministic DXF output.
5. Run a legal/provenance review for every code dependency and synthetic-to-vendor data transition.

## Days 31-60: prove workflow value with real permitted data

1. Obtain 3-5 anonymized SME BOMs and one reviewed panel drawing per scenario under written permission.
2. Normalize a small, provenance-tracked catalog slice for one manufacturer family and compare missing-field rates.
3. Implement duct-aware graph routing, terminal-level wire length, labels and a reviewable route diff.
4. Build an Excel/CSV import with stable IDs and a change-propagation report.
5. Benchmark heuristic, CP-SAT and a packing baseline on reviewed layouts; measure correction time and invalid-layout rate.

## Days 61-90: customer-facing pilot decision

1. Add schematic import/linking through a permissive adapter or isolated process, with round-trip fixtures.
2. Add optional 3D bounding-box/STEP preview from the same EIR; defer browser BREP unless measured demand justifies bundle/kernel cost.
3. Introduce a real LLM provider behind the existing intent interface, with field citations, confidence, schema rejection and deterministic replay.
4. Run a shadow pilot with two panel builders: compare BOM-to-DXF cycle time, correction count, and downstream CAD acceptance.
5. Decide whether to invest in a production wedge, change the wedge, or stop based on pre-registered thresholds rather than demo enthusiasm.

## Exit criteria

Proceed beyond pilot only if permitted data can be normalized, 30-part layouts
remain valid within a practical bound, engineers accept the DXF/BOM handoff,
and browser changes round-trip to one canonical EIR without semantic drift.
